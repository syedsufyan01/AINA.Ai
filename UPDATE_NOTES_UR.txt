RUN KARNE KA TAREEQA (Windows):
1. ZIP extract karo.
2. ANA folder VS Code mein open karo.
3. Terminal mein: npm install
4. Phir: npm run dev
5. Browser mein terminal ka Vite URL kholo (usually http://localhost:5173).

Note: Project ka source JavaScript syntax check pass hua. Is environment mein provided node_modules ka Vite/Rolldown native binding missing tha, is liye production build yahan verify nahi ho saka. Apne computer par npm install ke baad npm run build chala sakte ho.
